## 📌 Sobre o projeto

A **EcoVerde** é uma aplicação web institucional desenvolvida com o propósito de apresentar soluções sustentáveis para residências, aproximando tecnologia e natureza por meio de uma experiência digital moderna, intuitiva e responsiva.

O projeto apresenta alternativas para tornar os lares mais conscientes e eficientes, incentivando o uso inteligente dos recursos naturais, a redução de desperdícios e a adoção de práticas sustentáveis no cotidiano.

A interface foi planejada para transmitir uma identidade visual conectada à natureza, com navegação fluida, conteúdo organizado e elementos interativos.

## 🎯 Objetivos

- Promover a sustentabilidade por meio de soluções acessíveis.
- Apresentar alternativas para o uso consciente dos recursos naturais.
- Incentivar práticas que contribuam para a redução de desperdícios.
- Oferecer uma experiência digital agradável e intuitiva.
- Facilitar o contato de interessados com os serviços apresentados.

## ♻️ Soluções apresentadas

### ☀️ Energia solar residencial
Apresentação de soluções para geração de energia limpa, considerando consumo, incidência solar e características da residência.

### 💧 Captação de água da chuva
Soluções de captação, filtragem e armazenamento de água para atividades não potáveis, como irrigação e tarefas domésticas.

### 🌱 Compostagem doméstica
Incentivo ao reaproveitamento de resíduos orgânicos, transformando-os em composto natural para plantas e jardins.

### 🏡 Consultoria em sustentabilidade
Orientações para identificar oportunidades de melhoria e implementar mudanças sustentáveis de acordo com a realidade de cada residência.

## ✨ Funcionalidades implementadas

- **Página inicial:** apresentação da proposta e identidade da EcoVerde.
- **Carrossel principal:** imagens ilustrativas das soluções sustentáveis, com navegação manual e reprodução automática.
- **Seção de serviços:** apresentação das quatro soluções, com detalhes expansíveis.
- **Seção de benefícios:** destaque para autonomia, redução de desperdícios e investimento consciente.
- **Seção institucional:** apresentação da missão, visão e valores.
- **Carrossel institucional:** imagens relacionadas à sustentabilidade e ao cotidiano familiar.
- **Depoimentos:** componente interativo para navegação entre relatos apresentados na interface.
- **Formulário de consultoria:** coleta de nome, e-mail, telefone, serviço de interesse e mensagem.
- **Contato por e-mail:** preparação de uma solicitação por meio do aplicativo de e-mail padrão do dispositivo.
- **Navegação por seções:** acesso facilitado aos serviços, informações institucionais e contato.
- **Menu responsivo:** navegação adaptada a dispositivos móveis.
- **Rodapé institucional:** links de navegação e informações de contato.

## 🚀 Como executar o projeto localmente

### Pré-requisitos

- Node.js instalado.
- pnpm instalado.
- Git instalado.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd eco-verde
```

### 3. Instale as dependências

```bash
pnpm install
```

### 4. Execute em ambiente de desenvolvimento

```bash
pnpm dev
```

### 5. Acesse no navegador

```text
http://localhost:3000
```

### 6. Gere a versão de produção

```bash
pnpm build
```

### 7. Execute a versão de produção

```bash
pnpm start
```
