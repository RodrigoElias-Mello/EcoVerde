## 🌿 Sobre o projeto

A **EcoVerde** é um projeto web com identidade visual voltada à sustentabilidade e à preservação ambiental.

A proposta é apresentar alternativas para tornar as residências mais eficientes, conscientes e conectadas com a natureza, demonstrando como pequenas mudanças podem contribuir para um futuro mais sustentável.

O projeto foi desenvolvido com foco em uma experiência visual agradável, navegação intuitiva e comunicação clara dos serviços apresentados.

### 🎯 Objetivos

- Apresentar soluções sustentáveis para residências.
- Incentivar o consumo consciente de recursos naturais.
- Demonstrar alternativas para reduzir desperdícios.
- Facilitar o contato entre visitantes e a equipe.
- Transmitir uma identidade visual moderna, leve e conectada à natureza.

## ♻️ Soluções apresentadas

### ☀️ Energia solar
Apresentação de soluções para geração de energia limpa, autonomia residencial e melhor aproveitamento dos recursos solares.

### 💧 Captação de água da chuva
Soluções para captação, filtragem e armazenamento de água da chuva, destinada a atividades não potáveis.

### 🌱 Compostagem doméstica
Alternativas para reaproveitamento de resíduos orgânicos e produção de adubo natural.

### 🏡 Consultoria sustentável
Orientações para tornar os ambientes residenciais mais eficientes, reduzindo desperdícios e incentivando hábitos sustentáveis.

## ✨ Funcionalidades e recursos

- Página inicial com apresentação institucional.
- Seção de serviços e soluções sustentáveis.
